## Завдання 1. Коло й закон Ома — 15 хв

Новий **Circuit** у Tinkercad. **Без Arduino.**

Компоненти: **9V Battery**, **Resistor** 470 Ом, **LED**, два **Multimeter**.

```
+9 В → резистор 470 Ом → довша ніжка LED → коротша ніжка → амперметр → −9 В
```

1. **Прогноз:** яка напруга буде на світлодіоді? На резисторі?
2. Мультиметр у режимі **Voltage** — щупами на ніжки світлодіода. Потім на ніжки резистора.
3. Другий мультиметр у режимі **Current** — **в розрив** кола (уже стоїть за схемою).
4. Порахуйте за законом Ома: який резистор потрібен, щоб від **5 В** Arduino
   через світлодіод ішло **15 мА**? `R = (5 − U_LED) / 0,015`
5. Замініть резистор дротом і запустіть. Що сталося?

✔ Три числа в таблиці, розрахований R, скріншот `kolo.png`.

⚠️ Амперметр **паралельно** не ставити — це коротке замикання через прилад.

## Завдання 2. Цифровий пін — 10 хв

Нова схема з **Arduino Uno R3**, кнопкою й світлодіодом:

| Звідки | Куди |
|---|---|
| Pushbutton, одна пара ніжок | пін 2 |
| Pushbutton, протилежна пара | GND |
| пін 8 | резистор 220 Ом → довша ніжка LED |
| коротша ніжка LED | GND |

Скетч → `demo/d3_knopka.ino`.

1. `ZATRYMKA = 0`: 10 коротких натискань → скільки в Serial Monitor?
2. **Прогноз:** а з `ZATRYMKA = 1000`?
3. `ZATRYMKA = 1000`: ще 10 коротких натискань → скільки?

✔ Два числа «з 10 побачено …».

## Завдання 4. ШІМ — 15 хв

| Звідки | Куди |
|---|---|
| пін 9 (`~`) | резистор 220 Ом → довша ніжка LED |
| коротша ніжка LED | GND |
| Oscilloscope, «+» / «−» | пін 9 / GND |
| Multimeter (Voltage), «+» / «−» | пін 9 / GND |

Скетч → `demo/d5_shim.ino`. В осцилографа у властивостях **Time per division ≈ 1 ms**.

1. **Прогноз:** що покаже мультиметр при `ZNACHENNYA = 127`?
2. Значення 0, 64, 127, 191, 255. Для кожного: частка часу «ввімкнено» на
   осцилографі (на око: ¼, ½ …), мультиметр, яскравість словом.
3. Скріншот осцилографа при 64 → `oscylohraf.png`.

✔ П'ять рядків таблиці й скріншот.

## Завдання 5. Нічник: відчути → вирішити → діяти — 15 хв

| Звідки | Куди |
|---|---|
| 5V | Photoresistor → A0 |
| A0 | Resistor **10 кОм** → GND |
| пін 9 | 220 Ом → довша ніжка LED; коротша → GND |

Скетч → `demo/d6_nichnyk.ino`. Під час симуляції клацніть фоторезистор — з'явиться повзунок світла.

1. **Калібрування.** Повзунок на найтемніше й найсвітліше — запишіть `n` обох.
2. Поріг посередині → `PORIH`. `PROPORTSIYNO = false`. Працює?
3. Свої числа → `NMIN`, `NMAX`. `PROPORTSIYNO = true`. Чим відрізняється поведінка?

✔ `shema.png`, `sketch.ino` з **вашими** `PORIH`, `NMIN`, `NMAX`.

## Якщо щось пішло не так

| Що бачите | Причина | Що зробити |
|---|---|---|
| нічого не світить, мультиметр 0 | коло не замкнене | простежте шлях від «+» до «−» пальцем; найчастіше — немає дроту до GND |
| світлодіод не світить, а струм є | обернена полярність | довша ніжка — до «+» (через резистор) |
| амперметр показує 0, а все світить | амперметр стоїть паралельно | у розрив кола, послідовно |
| `n` завжди 0 або 1023 | повзунок потенціометра не на A0 або дільник без резистора 10 кОм | середній вивід → A0; для фоторезистора — пара з 10 кОм |
| осцилограф показує рівну лінію | масштаб занадто великий або пін без `~` | Time per division ≈ 1 ms; пін 9 |
| яскравість не змінюється | пін без ШІМ | тільки 3, 5, 6, 9, 10, 11 |
| код не компілюється | лишився старий код або режим Blocks | Code → Text, стерти все, вставити |

## Трек П

**Шум і фільтр.** Додайте до `n` у нічнику `random(-20, 21)` — біля порогу почнеться
мерехтіння. Приберіть його двома способами: **гістерезис** (два пороги, як у темі 4)
і **ковзне середнє** `f = 0.8 * f + 0.2 * n`. Що краще і чим платите за кожен?

## Трек Д

**Ручка, яку не треба пояснювати.** Потенціометр, кнопка, фоторезистор — три способи
людині сказати пристрою «яскравіше». Для кожного: яка дія людини природна, який
відгук світла вона чекає, де виникне непорозуміння. Що оберете для нічника в
дитячій кімнаті й чому?
